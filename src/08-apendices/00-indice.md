# Apéndices

Soluciones de referencia para los ejercicios guiados de los módulos intermedios (3.0–6.0). Consúltalas después de intentar cada ejercicio por tu cuenta, nunca antes.

## Cómo usar estos apéndices

- Cada solución asume que ya intentaste el ejercicio y no te cuadró el resultado, o que quieres contrastar tu enfoque con uno alternativo — no son la única forma correcta de resolver cada ejercicio, son *una* forma verificada de hacerlo.
- Todo el código de estos apéndices se compiló y ejecutó de verdad antes de publicarse (la misma disciplina de verificación del resto del libro) — si algo no compila en tu entorno, la causa más probable es una versión de crate distinta a la fijada en el capítulo correspondiente, no un error de transcripción.

## Mapa: apéndice → módulo del libro

```text
Apéndice — Módulo 1  <-  Parte II  (Fundamentos de Rust, 2.1-2.5)
Apéndice — Módulo 2  <-  Parte III (Primitivas Geoespaciales, 3.1-3.5)
Apéndice — Módulo 3  <-  Parte IV  (Índices, Robustez y Persistencia, 4.1-4.7)
Apéndice — Módulo 4  <-  Parte V   (Concurrencia, Cloud-Native y FFI, 5.1-5.7)
Apéndice — Módulo 5  <-  Parte VI  (Arquitectura de Producción, 6.1-6.6)
```

El Módulo Final (capstones, Parte VII) no tiene apéndice de soluciones — su criterio de aceptación es una suite de tests, un benchmark o una tabla de trazabilidad que tú mismo produces, no un ejercicio con solución única.
